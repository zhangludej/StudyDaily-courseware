# StudyDaily 视频课件

App 端通过 raw 直链 + Range 边下边播，看过的课自动缓存到本机。

- `videos/u01` 拼音 34 集
- `videos/u02` 识字 32 集
- `videos/u03` 数学 34 集（其中 4 集为适配 100MB 单文件上限做过轻度重编码）
- `videos/u04` 英语 20 集

访问方式（任选其一，均支持 Range）：

```
https://raw.githubusercontent.com/zhangludej/StudyDaily-courseware/main/videos/u01/001.mp4
https://gh-proxy.com/https://raw.githubusercontent.com/zhangludej/StudyDaily-courseware/main/videos/u01/001.mp4
https://ghfast.top/https://raw.githubusercontent.com/zhangludej/StudyDaily-courseware/main/videos/u01/001.mp4
```
